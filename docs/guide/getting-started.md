# Getting Started

Learn how to install and use ts-open-api to generate TypeScript types from OpenAPI schemas.

## Prerequisites

- Bun 1.0+ or Node.js 18+
- An OpenAPI 3.0 or 3.1 schema (JSON or YAML)

## Installation

```bash
# Using bun
bun add -D ts-open-api

# Using npm
npm install -D ts-open-api

# Using pnpm
pnpm add -D ts-open-api

# Using yarn
yarn add -D ts-open-api
```

## Quick Start

### CLI Usage

Generate types from a local schema:

```bash
open-api ./openapi.json --output ./api-types.ts
```

Generate from a remote schema:

```bash
open-api https://api.example.com/openapi.json --output ./api-types.ts
```

### Programmatic Usage

```typescript
import { generateTypes } from 'ts-open-api'

await generateTypes({
  input: './openapi.json',
  output: './api-types.ts',
  alphabetize: true,
  immutable: true,
  includeDescriptions: true
})
```

## Basic Example

### Input OpenAPI Schema

```json
{
  "openapi": "3.0.0",
  "info": {
    "title": "My API",
    "version": "1.0.0"
  },
  "components": {
    "schemas": {
      "User": {
        "type": "object",
        "required": ["id", "name"],
        "properties": {
          "id": { "type": "string" },
          "name": { "type": "string" },
          "email": { "type": "string" }
        }
      }
    }
  }
}
```

### Generated TypeScript

```typescript
/**
 * This file was auto-generated by ts-open-api.
 * DO NOT MAKE DIRECT CHANGES TO THE FILE.
 */

// Component Schemas

export interface User {
  "id": string
  "name": string
  "email"?: string
}
```

## Configuration Options

### Basic Options

```typescript
await generateTypes({
  // Required
  input: './openapi.json',      // Path to OpenAPI schema
  output: './api-types.ts',     // Output file path

  // Type generation
  alphabetize: true,            // Sort types alphabetically
  immutable: true,              // Generate readonly properties
  exportType: false,            // Use 'type' instead of 'interface'

  // Documentation
  includeDescriptions: true,    // Include JSDoc descriptions
  includeExamples: true,        // Include @example in JSDoc

  // Output
  silent: false                 // Suppress console output
})
```

### Advanced Options

```typescript
await generateTypes({
  input: './openapi.json',
  output: './api-types.ts',

  // Nullability
  defaultNonNullable: false,    // Treat schemas as non-nullable by default

  // Additional properties
  additionalProperties: false,  // Allow arbitrary properties via index signature

  // Path parameters
  pathParamsAsTypes: false,     // Generate path params as string literals

  // Array validation
  supportArrayLength: false,    // Support array length validation

  // Custom transformations
  transform: (schema) => schema,
  postTransform: (typescript) => typescript,

  // Custom header
  header: true,
  headerComment: '/* Custom header */'
})
```

## Output Modes

### Interface Mode (Default)

```typescript
export interface User {
  "id": string
  "name": string
}
```

### Type Mode

With `exportType: true`:

```typescript
export type User = {
  "id": string
  "name": string
}
```

### Immutable Mode

With `immutable: true`:

```typescript
export interface User {
  readonly "id": string
  readonly "name": string
}
```

## Handling Different Schema Types

### Objects

```json
{
  "User": {
    "type": "object",
    "properties": {
      "id": { "type": "string" },
      "name": { "type": "string" }
    }
  }
}
```

```typescript
export interface User {
  "id"?: string
  "name"?: string
}
```

### Enums

```json
{
  "Status": {
    "type": "string",
    "enum": ["active", "inactive", "pending"]
  }
}
```

```typescript
export type Status = "active" | "inactive" | "pending"
```

### Arrays

```json
{
  "UserList": {
    "type": "array",
    "items": { "$ref": "#/components/schemas/User" }
  }
}
```

```typescript
export type UserList = User[]
```

### Unions (oneOf)

```json
{
  "Response": {
    "oneOf": [
      { "$ref": "#/components/schemas/Success" },
      { "$ref": "#/components/schemas/Error" }
    ]
  }
}
```

```typescript
export type Response = (Success | Error)
```

### Intersections (allOf)

```json
{
  "Admin": {
    "allOf": [
      { "$ref": "#/components/schemas/User" },
      { "type": "object", "properties": { "role": { "type": "string" } } }
    ]
  }
}
```

```typescript
export type Admin = (User & {
  "role"?: string
})
```
